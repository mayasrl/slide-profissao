# 💙 O que eu Realmente Faço no Trabalho

Apresentação interativa, divertida e animada sobre a rotina profissional na área de dados, desenvolvida em formato de slides web com uma estética fofa inspirada no **Doraemon**.

O projeto transforma uma apresentação tradicional em uma experiência visual, dinâmica e navegável diretamente pelo navegador.

**[➡️ Acesse a demonstração ao vivo](https://mayasrl.github.io/slide-profissao/)**

---

## 📋 Sobre o Projeto

O **O que eu Realmente Faço no Trabalho** é uma apresentação interativa criada com HTML, CSS e JavaScript, pensada para explicar de forma leve e bem-humorada atividades relacionadas à área de dados, automações, dashboards, organização de informações e resolução de problemas no ambiente profissional.

A proposta do projeto é fugir do formato tradicional de apresentação e criar uma experiência visual com slides animados, elementos temáticos, navegação interativa e uma identidade divertida.

A apresentação utiliza uma estrutura própria de slideshow, com múltiplos slides, animações, barra de progresso e navegação por botões, teclado e toque em dispositivos compatíveis.

---

## ✨ Funcionalidades Principais

- **Apresentação em formato web**: Slides desenvolvidos diretamente em HTML.
- **Tema visual inspirado no Doraemon**: Paleta azul, elementos fofos, nuvens, estrelas e imagens temáticas.
- **Slides animados**: Transições, efeitos visuais e entrada de elementos em cada tela.
- **Navegação interativa**: Avance ou volte pelos slides usando botões, teclado ou gesto de toque.
- **Barra de progresso dinâmica**: Indica o slide atual e permite navegação pelos pontos da apresentação.
- **Layout 16:9**: Estrutura visual no formato de apresentação, com proporção de 960x540.
- **Componentes visuais reutilizáveis**: Cards, painéis, imagens, destaques e elementos decorativos.
- **JavaScript modular**: Controle separado para navegação e atualização dos slides.
- **CSS organizado por seções**: Estilos de layout, animações, slides, cards e elementos temáticos.
- **Experiência divertida e profissional**: Mistura humor, storytelling e visual bem estruturado.

## 📊 Como Funciona

O projeto funciona como um slideshow web:

1. **Estrutura dos slides**  
   Cada tela da apresentação é representada por uma seção `.slide` no HTML.

2. **Estilização visual**  
   O CSS define o layout, as animações, os elementos decorativos e a identidade visual.

3. **Controle de navegação**  
   O JavaScript identifica o slide atual, troca as telas, atualiza a barra de progresso e permite interação por botões, teclado e toque.

O objetivo do projeto é criar uma apresentação técnica, criativa e memorável, mostrando de forma bem-humorada o que realmente acontece no trabalho de quem atua com dados, automação e tecnologia.

- Estruturação semântica com HTML
- Organização de estilos com CSS
- Criação de animações e transições
- Manipulação do DOM com JavaScript
- Navegação entre estados visuais
- Construção de slideshow personalizado
- Organização de assets e arquivos estáticos
- Design visual aplicado a apresentações web
